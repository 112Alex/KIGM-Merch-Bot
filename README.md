# Бот КИГМ Мерч

Телеграм-бот для учета и управления мерч-продукцией колледжа. Бот позволяет студентам накапливать баллы за участие в мероприятиях и использовать их для покупки мерча.

## Функциональность

### Для пользователей
- Регистрация в системе
- Просмотр доступных мероприятий
- Подача заявок на участие в мероприятиях
- Просмотр накопленных баллов
- Покупка мерч-продукции колледжа за накопленные баллы

### Для администраторов
- Добавление, изменение и удаление мероприятий
- Проверка и оценка заявок студентов
- Начисление баллов за участие в мероприятиях
- Просмотр списка всех купленных товаров
- Выгрузка данных о купленных товарах в Excel

## Технологии
- Python 3
- aiogram 3.x
- SQLAlchemy (ORM)
- База данных PostgreSQL
- Pydantic для валидации данных
- Docker и Docker Compose для контейнеризации
- Python-dotenv для конфигурации (должен содержать константы BOT_TOKEN и KIGM_MERCH_DB для подключения к базе данных)

## Запуск проекта

Проект разработан с использованием Docker для удобства развертывания.

1.  **Клонировать репозиторий:**
    ```bash
    git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
    cd KIGM-Merch-Bot
    ```
2.  **Настроить переменные окружения:**
    Создайте файл `.env` в корневой директории проекта со следующим содержимым:
    ```
    BOT_TOKEN=ваш_токен_от_BotFather
    KIGM_MERCH_DB=postgresql+asyncpg://postgres:password@db:5432/kigm_merch_db # Пример для Docker
    ADMIN_IDS=список_id_администраторов_через_запятую
    ```
    *   Замените `ваш_токен_от_BotFather` на актуальный токен вашего Telegram бота.
    *   `KIGM_MERCH_DB` уже настроен для подключения к PostgreSQL в Docker.
    *   `ADMIN_IDS` должен содержать Telegram ID администраторов, разделенные запятыми.

3.  **Запустить проект с помощью Docker Compose:**
    Убедитесь, что Docker Desktop (или Docker Engine) запущен. Затем выполните команду в корневой директории проекта:
    ```bash
    docker compose up --build -d
    ```
    Эта команда соберет Docker-образы (при необходимости) и запустит контейнеры для бота и базы данных PostgreSQL в фоновом режиме.

4.  **Остановить проект:**
    ```bash
    docker compose down
    ```
